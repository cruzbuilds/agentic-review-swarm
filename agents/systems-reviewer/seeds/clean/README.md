# tickets

Support tickets. Rules:

- A ticket is visible to its requester and to agents.
- Lifecycle: `OPEN -> PENDING -> RESOLVED -> CLOSED`. `PENDING -> OPEN` when the requester
  replies. A CLOSED ticket cannot change; the requester opens a new one.
- The requester's satisfaction score is recorded once, when the ticket is resolved, and is
  what the weekly CSAT report averages.
